# How to Build.

```
1. Step 1 — Create the project folder and initialize it.

    mkdir mini-chain && cd mini-chain
    npm init -y

2. Step 2 — Switch the package to ES modules and install the TypeScript tooling.

    Add `"type": "module"` to the generated `package.json`, then run:

    npm install --save-dev typescript@6 tsx @types/node

3. Step 3 — Add `tsconfig.json`.

4. Step 4 — Write `chain.ts`.

5. Step 5 — Run it.

    npx tsx chain.ts
```
