# For someone cloning.

Simply reinstall the dependencies.

```
forge install foundry-rs/forge-std
forge build
```

---

# How to Build.

```
1. Scaffold, same pattern as Easy.

     forge init security-medium --no-git
     cd security-medium

2. Set the same solc pin as every previous week.

3. Create all three src/ files and both test/ files from the Solution
   below.

4. Build and run.

     forge build
     forge test -vv

   You should see 3 tests, all passing.
```
