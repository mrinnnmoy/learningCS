**How to Build:**

```
1. Step 1 — Create the project folder and initialize it.

    Run:
    mkdir toolchain-doctor && cd toolchain-doctor
    npm init -y

2. Step 2 — Set the package to use modern ES module syntax.

    Open the generated `package.json` and add `"type": "module"`.

3. Step 3 — Write `check.js`.

    See the Solution section below for the full file.
    Create it in the project root.

4. Step 4 — Run it.

    node check.js
```
